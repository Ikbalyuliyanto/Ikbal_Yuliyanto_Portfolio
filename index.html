📄 Cara Download PDF dengan Warna Lengkap

  1. Klik tombol "Print / Cetak" di bawah
  2. Di dialog print, pilih Destination → Save as PDF
  3. Klik "More settings" (atau Opsi Lanjutan)
  4. Centang ✅ "Background graphics" (Grafis Latar Belakang)
  5. Klik Save
